=====================================================================
1. BRAND IDENTITY (logo / marketing layer)
=====================================================================

Primary palette
  ink          #101820   wordmark, symbol lines on light, primary text
  paper        #F5F3EE   light backgrounds, reversed wordmark on dark
  dark         #0C121D   app-icon tile, dark surfaces, "reversed on ink"
  signal       #FF5A1F   the accent: merged beam, node, ping ring,
                         active states. The one loud color — use sparingly.

Supporting neutrals
  muted        #66707B   secondary text on paper
  faint        #DFDCD4   hairlines, dividers on paper
  line-dark    #A9B5C1   symbol lines on dark backgrounds
  text-dark    #8B96A3   secondary text / captions on dark backgrounds

Severity dots (the four pips of the symbol, top to bottom)
  sev-critical #E5484D
  sev-warning  #F5A524
  sev-info     #4C8DFF
  sev-notice   #98A2AD

Usage rules
  - Signal orange is reserved for the "single managed signal" idea:
    the merged beam/node, the active nav underline, primary CTAs.
  - Severity colors appear ONLY as the four source pips and for
    severity semantics in the product UI — never as decoration.
  - The symbol works single-color (all ink, or all white); color pips
    are the full-color variant only.

Semantic tokens (every pack defines these)
  --bg --surface --border --text --text-muted --accent --accent-hover

  --badge-fg         foreground on red/green/blue fills
  --badge-fg-warm    foreground on amber/orange/yellow fills
  --severity-critical / --severity-high / --severity-warning / --severity-info
  --status-firing / --status-ack / --status-resolved / --status-stalled
  --status-closed / --status-suppressed

  --brand-signal #FF5A1F  --brand-signal-hover  --on-brand-signal

                     white/paper ~3.1:1 fails AA)

Brand-pack notes
  - Built strictly from §1 palette + neutrals; the only derived values
    are surface/border darks, the suppressed grays, and accent-hover.
  - Registration points for a new pack: static/app.css [data-theme]
    block, Application.Helper.Theme (themes + bsTheme), static/app.js
    THEMES/LIGHT_THEMES (client-side picker validation — forgetting
    this makes the picker silently do nothing), Provision.hs
    settings.theme validation, Test/ThemeSpec, playwright theme
    snapshot loop in tests/playwright/run.py.

Contrast rule (enforced by the 2026-09 patch)
  Text on saturated fills must reach WCAG AA 4.5:1:
  dark packs  -> page-bg dark text on pastel fills
  latte       -> white on cool fills, #2E2300 on warm fills

=====================================================================
3. BRAND FONTS
=====================================================================

Identity / marketing
  Space Grotesk   wordmark ("halemans", lowercase), display headlines
                  Google Fonts · SIL OFL
  JetBrains Mono  annotations, labels, version tags, captions
                  Google Fonts · SIL OFL

Product UI (self-hosted in /static/vendor/fonts, no CDN)
  Inter (variable, weights 100–900)   UI text
                  token: --font-sans
  JetBrains Mono (400, 700)           code, timestamps, version badges,
                  token: --font-mono     numeric chips

Type scale (product)
  --text-xs   0.70rem   labels, captions, version pill
  --text-sm   0.75rem   secondary text
  --text-md   0.85rem   nav items, dense body
  --text-base 1rem      body
  --text-lg   1.25rem   card/page titles

Typography rules
  - Numbers that change live (counts, badges, times) use
    font-variant-numeric: tabular-nums.
  - Uppercase labels: letter-spacing 0.06–0.08em, weight 600,
    color --text-muted.
  - Wordmark is always lowercase "halemans"; product name in prose is
    "Halemans".
